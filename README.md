## 👋 About me

I'm a **fullstack and mobile software engineer** specialized in **institutional platforms, performance and DevOps**. I design, build and ship end-to-end products — from the database and API to the web or mobile interface and the pipeline that deploys it — and I'm **open to full-time, contract and freelance work, remote worldwide**. Based in **LATAM**.

- 🏛️ Built **GET (Technology Equipment Management)**, a component and tooling platform that unified the products of the **Ministry of Education of the Dominican Republic**.
- ⚙️ Implemented **CI/CD** practices that cut errors and deployment times by **over 73%**.
- 🗄️ Led database performance work on a national system: 3NF normalization, stored procedures and indexing.
- 🏥 Delivered healthcare scheduling systems serving **5,000+ patients per day**, and freelance products reaching **10,000+ users daily**.
- 📱 Web with **React, Next.js, Angular and Astro**; mobile with **Flutter and React Native**.
- 🌎 Fluent in **English** (professional) and **Spanish** (native).
